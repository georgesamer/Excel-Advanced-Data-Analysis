# 📊 Advanced Excel E-Commerce & Financial Analytics Dashboard

A comprehensive data analysis and business intelligence project built entirely using **Microsoft Excel**, utilizing advanced data engineering and modeling techniques.

## 🚀 Key Features & Workflow

1. **Data Extraction & Transformation (Power Query):**
   - Imported and cleaned multi-source CSV files (Amazon sales reports, financial statements, and expense records).
   - Performed data type casting, filtering, and merging to prepare clean staging tables.

2. **Data Modeling & Relationships (Power Pivot & DAX):**
   - Established a robust relational **Data Model** linking sales and expense tables via primary/foreign keys (`index`).
   - Utilized calculated measures for financial aggregation.

3. **Data Validation & Quality Control:**
   - Implemented error handling and structured validation workflows to maintain data integrity.

4. **Interactive Dashboard & Visualization:**
   - Designed dynamic **PivotTables** and **PivotCharts** (Clustered Column charts) to analyze revenue distribution across categories and merchant channels.
   - Added interactive **Slicers** to filter dashboard insights seamlessly.

## 🛠️ Tools & Technologies Used
- **Microsoft Excel** (Advanced Formulas, PivotTables)
- **Power Query** (ETL Pipeline)
- **Power Pivot & DAX** (Data Modeling)
- **Data Validation & Error Handling**
